# Motari builds

Android builds of **Motari**, the moto taxi app for [MpahMapu](https://mpahmapu.com).

Ask for a moto or send a delivery in a few taps, and follow it on the map.
Motari sign in to take the work, get paid, and settle the daily fee.

## Download

Get the current build from [Releases](../../releases/latest), or from
[mpahmapu.com/app](https://mpahmapu.com/app), which always points at the same file.

Android will ask you to allow installing it. That is normal for an app that
does not come from the Play Store.

## Why this repository exists

It holds the builds and nothing else, so the download is public without the
source being public. There is no code here. Issues belong on the site.
